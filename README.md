Bio7 — Application E-commerce Cosmétiques Bio

Bio7 est une application web permettant de présenter et gérer des produits cosmétiques bio et artisanaux.
Le projet utilise une architecture moderne basée sur React pour le frontend, Spring Boot pour le backend, et MySQL pour la base de données.

 Stack Technique

React => Interface utilisateur moderne et dynamique

Spring Boot => API backend rapide et sécurisée

MySQL => Base de données relationnelle pour stocker les produits

Ce projet a pour but de créer une boutique simple et efficace avec un design propre et un backend robuste.
